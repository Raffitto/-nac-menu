# NAC admin UI QA

Provenance: MengTo Skills inspected; marketing/WebGL/landing kits rejected. This skill is NAC-written for operational admin UI.

- Keep existing visual system. Do not import glass/orb/particle landing aesthetics.
- Hierarchy: title → period/branch → first useful metric → enrichment.
- Interaction QA: click, type, submit, navigate. Screenshot-only is not verification.
- Responsive: check a desktop and a narrow viewport when layout changes.
- Loading, stale, unauthorized, and empty states must stay distinct.
